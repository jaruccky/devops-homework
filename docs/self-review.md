# Само-ревью

- Уточнение преподавателя отражено: Ansible выполняется перед Terraform; Terraform использует `kreuzwerker/docker`.
- Terraform nginx подключён к новой отдельной сети и именованному тому, порт `8080`.
- Compose reverse proxy и app подключены исключительно к своей сети, app не публикует порт.
- Playbook использует декларативные модули для пакетов, пользователя, sudo, SSH и systemd. Информационная команда dpkg имеет `changed_when: false`. Реальное `changed=0` пока требует доступного сервера.
- SSH-конфигурация проверяется до reload; пароль deployer заблокирован, ключ добавляется без удаления существующих ключей.
- Docker API не опубликован по незащищённому TCP.
- Мониторинг обрабатывает неверные аргументы, отсутствующий сервис и журналы, время и смену года; десять тестов проходят.
- Учитываются два формата syslog и timezone offsets; счётчик не включает старые и будущие записи.
- Terraform state и учётные данные исключены из Git; исходный task с паролем вне репозитория.
- Подготовлены проверки HTTP, тома, здоровья и разделения сетей, сбор фактических логов.
- Не подтверждены: Terraform provider schema/runtime, apply, идемпотентность на VM, nginx HTTP, удалённые сети/том и публикация PR/MR. Причины: SSH timeout, недоступные загрузки Terraform и отсутствие рабочей GitHub-авторизации.
